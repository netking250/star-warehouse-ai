## Implementation plan

1. Harden existing workflows without changing the five accepted job names or coverage threshold.
2. Add a read-only PR/main/tag supply-chain workflow for Gitleaks, locked backend/frontend audits,
   image build/scan, CycloneDX SBOM, and safe image metadata artifacts.
3. Add trusted-context-only artifact provenance attestation; do not publish images or expose write
   credentials to PR code.
4. Add minimal trusted-context CodeQL and PR dependency-review coverage where GitHub supports it.
5. Pin the existing third-party setup-uv action, retain Dependabot as the only update automation,
   and add Docker image update coverage without adding Renovate.
6. Document the gate architecture, scanner policy, artifact retention, cache boundary, known
   exceptions, and T21 hosted-PR acceptance evidence.
7. Run bounded local CI-equivalent checks, validate workflow/config syntax, update execution state,
   commit as one conventional T18 change, and push normally.
