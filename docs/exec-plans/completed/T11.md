## Behavior-First Plan

1. Build a complete code-backed dataset classification/lifecycle registry and structural guard.
2. Add bounded, tenant-scoped retention planning/execution with dry-run, deterministic clocks,
   kill-switch, metrics, and tenant-safe local file deletion.
3. Add append-only compliance audit events and enforce database immutability for both compliance
   and authorization audit tables against runtime and application SUPER_ADMIN access.
4. Add parameter-bound, tenant-bound, expiring, single-use approval requests and gate the existing
   feedback CSV export through T09 capabilities with current authorization revalidation.
5. Add the additive T11 migration with forced RLS, immutable triggers/grants, and inventory guards.
6. Add focused APIs, route classifications, metrics tests, PostgreSQL boundary tests, and runbooks.
7. Run targeted pytest groups, scoped Ruff/format/ty, and `alembic heads`; do not run the full suite
   or start T12.

## Execution Notes

- Product-undefined retention periods are conservative configurable DEV/DEMO engineering defaults,
  not legal requirements.
- Audit data is retained indefinitely in T11; no audit purge policy is introduced.
- Sensitive feedback export remains synchronous and bounded, so no new async export platform is
  introduced.
